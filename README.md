#  JS-Calculator 🧮

A functional web calculator built to practice **DOM manipulation** and **JavaScript logic**. This project focuses on handling mathematical strings and implementing error-prevention sequences.

---

## 🚀 Key JavaScript Features
* **Mathematical Evaluation:** Uses `eval()` to process calculations directly from the input string.
* **Error Handling:** Implemented a `try...catch` block to display a clean "Error" message instead of crashing the app on invalid syntax (e.g., `5++5`).
* **String Manipulation:** Utilizes the `.slice(0, -1)` method to create a functional **DEL** (Backspace) feature.
* **State Management:** Includes an **AC** (All Clear) function to reset the calculator state instantly.

## 🎨 UI & Design
* **Themed Interface:** Dark-mode design using CSS variables (`:root`) for consistent color management.
* **Layout:** Centered using **Flexbox** to ensure a clean desktop presentation.



---

## 🛠️ Built With
* **HTML5:** Semantic structure for the calculator buttons and display.
* **CSS3:** Custom styling with soft shadows and button shapes.
* **Vanilla JavaScript:** Pure logic without external libraries or frameworks.

## 📂 How to Run
1. Clone this repository.
2. Open `index.html` in any modern web browser.
